# Project Selection Framework

1. Choose a target role.
2. Map required skills.
3. Identify gaps.
4. Select projects that cover different capabilities.
5. Build one flagship project with depth.

Suggested skill dimensions: Python, Data, ML, Deep Learning, LLMs, Prompting, Structured Output, RAG, Agents, APIs, UI, Evaluation, Security, Governance, Observability, Deployment, Cloud/Hybrid, Business Value.
